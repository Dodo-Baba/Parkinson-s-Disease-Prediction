# Parkinson-s-Disease-Prediction

This repository contains code and resources for a machine‑learning project that predicts motor‐symptom severity (UPDRS Part III score) in people with Parkinson’s disease.  
The model ingests both **clinical variables** (age, sex, disease duration, medication status, etc.) and **biomarker features** (protein/peptide abundance, NPX values, imaging‑derived scores, …​) to forecast a patient’s next UPDRS‑III measurement.  

To check out the project go to: https://www.kaggle.com/code/dodobaba/parkinson
